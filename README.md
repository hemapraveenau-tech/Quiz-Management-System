A simple Python console-based Quiz Management System using functions.

Features

-  Admin can add, modify, and delete quizzes/questions.
-  Students can view available quizzes and answer questions.
-  Students can submit quizzes and view their scores.
-  Built using basic Python concepts like functions, lists, loops, and conditions.

Technologies

- Python
- Console Application
